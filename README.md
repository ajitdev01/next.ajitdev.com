## 📖 About The Project

**`next.ajitdev.com`** is the central high-performance web engineering hub and developer ecosystem engineered by **Ajit Dev**. Built from the ground up on bleeding-edge modern web standards, it demonstrates enterprise-grade full-stack architecture, zero-compromise security, local-first sovereignty, and observability:

- 💳 **Production Razorpay Direct Payment Gateway (`/payments/test`)**: Custom INR amounts, preset quick-add chips (+₹100, +₹500, +₹1,000), modal checkout, server-side cryptographic HMAC-SHA256 signature verification, persistent MongoDB records with connection pooling, and isolated `@media print` receipts.
- 🧾 **Payments Sandbox & Transaction Explorer (`/payments/testlist`)**: Real-time financial activity cards showing status pills, copyable payment IDs, order volume metrics, and printable digital receipts for past orders.
- 💱 **Real-Time Global Currency Converter (`/currency`)**: European Central Bank (ECB / Frankfurter) live forex rates across 31 world currencies with sub-second ISR caching, interactive SVG historical timeseries chart (7D/30D/90D/1Y curves), 12-currency live parity matrix, and 2x Retina snapshot card generator with instant multi-channel social sharing (WhatsApp, Telegram, 𝕏, clipboard image copying).
- 🛒 **Refresh-Safe E-Commerce Experience (`/store`)**: 50+ products across tech, apparel, and accessories, instant fuzzy search, category filtering, dynamic coupon validation (`DEV10`, `SUPER20`, `FREESHIP`), 2x Retina snapshot card sharing, and Redux Toolkit cart persistence synced to `localStorage`.
- 🤖 **AJITDEV Cloud Assistant**: Agentic AI chat assistant powered by `@google/genai` (Google Gemini Flash 3.x) with dual API-key round-robin load balancing, server-side proxy protection, multi-model fallback, and grounding in a 28-category developer knowledge base.
- 📊 **Enterprise Observability & Error Tracking (PostHog & Vercel)**: Next.js 15.3+ client instrumentation (`instrumentation-client.ts`) and server exception forwarding (`instrumentation.ts` via `onRequestError`), ad-blocker bypassing reverse proxy (`/ingest`), automated source map upload with post-build deletion, Web Analytics, Session Replay, and heatmaps.
- 🔐 **NextAuth v5 Beta & Protected Member Dashboard (`/dashboard`, `/login/google`)**: Google OAuth 2.0 PKCE session authentication, server-side route guards, authenticated user profile, celebration confetti, and PostHog user identification.
- 📱 **Progressive Web App (PWA) & Offline Shell (`/download`)**: Standalone mobile and desktop launcher, custom app intro splash screen (`app-intro-splash.tsx`), service worker offline caching (`/sw.js`), and Web App Manifest (`manifest.ts`).
- 🌤️ **Atmospheric Weather Intelligence (`/weather`)**: Real-time OpenWeatherMap measurements with geocoding, server route proxy, and offline mock resilience.
- 🛡️ **Sovereign Local-First Tools (`/note`, `/todo`)**: Zero network dependency, 0ms interaction latency with IndexedDB, and 1-click JSON backup/restore.
- ⚡ **Interactive Developer API Console (`/api`)**: Public REST endpoint explorer with live testing, schema viewers, and response metrics.
- 🔍 **Enterprise SEO & Semantic Graph Engine (`seo/keyword-map.csv`, `lib/seo`)**: 350+ keyword mapping matrix, Schema.org connected JSON-LD graph (`WebSite`, `Person`, `Organization`, `WebPage`, `BreadcrumbList`), dynamic OG images via `@vercel/og` (`/opengraph-image`), RSS/Atom syndication (`/feed.xml`, `/rss.xml`), dynamic `sitemap.ts`, and `robots.ts`.

## 💳 Payment Gateway Architecture & Security Flow

```
[User Browser]
      │
      │ 1. Enter Custom Amount / Quick Chip & Click "Pay Now"
      ▼
[POST /api/payment/create-order] (Server-Side)
      │
      │ 2. Validate Amount Range (₹1 – ₹5,00,000) & Initialize Razorpay Order
      ▼
[Razorpay API Gateway]
      │
      │ 3. Returns order_id (e.g. order_TeLwCoFUKoyfbj)
      ▼
[MongoDB Atlas] ──► Pre-saves order record in collection 'payments' with status: 'created'
      │
      │ 4. Client launches Razorpay Modal Checkout
      ▼
[User Completes Payment (UPI / Card / NetBanking / Wallet)]
      │
      │ 5. Modal returns: razorpay_payment_id, order_id, razorpay_signature
      ▼
[POST /api/payment/verify] (Server-Side)
      │
      │ 6. HMAC-SHA256: crypto.createHmac('sha256', SECRET).update(`${order_id}|${payment_id}`)
      │ 7. Constant-Time Verification: crypto.timingSafeEqual(expectedBuffer, actualBuffer)
      ▼
[MongoDB Atlas] ──► Updates status to 'success', saves payment method, timestamp & verifiedAt
      │
      │ 8. Client fires Confetti Burst + renders isolated printable receipt
      ▼
[Clean Digital Receipt Card (@media print optimized)]
```

## 🔒 Security Best Practices

- **Zero Client Secret Exposure**: Secrets like `RAZORPAY_KEY_SECRET`, `DATABASE_MONGODB_URI`, `AUTH_SECRET`, and `GEMINI_API_KEY` are kept strictly on the server and are never bundled or prefixed with `NEXT_PUBLIC_`.
- **Constant-Time Cryptographic Verification**: Payment verification uses `crypto.timingSafeEqual` over SHA-256 HMAC buffers to prevent timing side-channel attacks.
- **Connection Pooling in Serverless**: MongoDB connections use `@vercel/functions` `attachDatabasePool` to prevent pool exhaustion across serverless lambdas.
- **Hardened HTTP Headers**:
  - `Alt-Svc: h3=":443"; ma=86400, h3-29=":443"; ma=86400` (HTTP/3 & QUIC advertisement)
  - `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload`
  - `X-Content-Type-Options: nosniff`
  - `X-Frame-Options: SAMEORIGIN`
  - `Referrer-Policy: strict-origin-when-cross-origin`
  - `Permissions-Policy: camera=(), microphone=(), geolocation=(), browsing-topics=()`
- **Ad-Blocker Proof Analytics**: PostHog telemetry is routed through first-party reverse proxy rewrites (`/ingest/*`), eliminating event drops while adhering to strict privacy masking.
- **Strict Git Exclusions**: Both `.env` and `.env.local` are explicitly blocked in `.gitignore` and `.vercelignore`.
